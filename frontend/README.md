# netflix 🎬

netflix is a React-based movie discovery application that allows users to explore movies and web series through a modern streaming-style interface.

## Features

- Browse movies and web series
- Search by title, genre, director, cast, and description
- Filter content by Movies or Series
- Sort titles by rating and release year
- View detailed movie information
- View director and cast information
- Watch movie trailers
- Add movies to Favorites
- Remove movies from Favorites
- Favorites are saved using Local Storage
- Responsive and modern user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Local Storage
